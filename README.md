# Björn Müller — Research Website

Static GitHub Pages website.

## Edit
- Main text: `index.html`
- Design: `styles.css`
- Images: `assets/`
- CV: place your PDF at `files/CV.pdf`
- Replace placeholder publication/profile links (`href="#"`) in `index.html`.

## Publish
Create a GitHub repository named `YOUR-USERNAME.github.io`, upload the contents of this folder to the repository root, then enable GitHub Pages from the `main` branch and `/ (root)`.
